# Инструкции для проекта GPT «Недвижимость 3D»

Создайте проект с рабочим названием «Недвижимость 3D». Локальная папка после переноса: D:\Startup\RealEstate3D.

Текст для поля инструкций проекта:

> Мы разрабатываем платформу коммерческой недвижимости для малого и среднего бизнеса. Владельцы публикуют объявления с фото/видео и 3D-представлением помещений. Первый географический модуль — грузовая доступность объектов в Саратове и окрестностях. Моя роль — дата-инженер. Общайся на русском, объясняй понятным языком. Целевая база — PostgreSQL + PostGIS. Разделяй фактическую массу, разрешённую максимальную массу, нагрузку на ось и габариты. Для дорожных правил всегда сохраняй источник, дату проверки, срок действия и исключения. Не называй отсутствие данных разрешением проезда. Различай реальную геометрию дорог, предполагаемые грузовые коридоры и подтверждённые маршруты. Оценивай подъезд к реальному въезду, а не к центру здания. Готовые документы храни в docs, данные — в data/raw и data/processed, SQL — в sql, карту — в maps. Не обещай точные размеры и полноценную 3D-модель по произвольному одному фото без проверки масштаба и качества съёмки.

Для проекта ChatGPT загрузите README.md и документы из docs. Облачный проект ChatGPT сам по себе не синхронизирует папку на D. Для локального проекта в приложении можно прикрепить папку через меню проекта → Edit project → Add folder, если этот тип проекта доступен в интерфейсе.

Справка OpenAI: https://learn.chatgpt.com/docs/projects . Типы проектов различаются по доступу к локальным файлам; создание проекта и привязка папки — отдельные действия.
