# Проверка подготовленного набора

Дата: 27 октября 2026 года.

- Снимок OSM: 2026-10-27 18:23:02 UTC.
- 39 796 уникальных OSM-линий; 2 301 точка; 546 отношений запретов поворота.
- У всех сохранённых линий не менее двух точек; координаты в допустимых диапазонах. Отброшенных линий нет.
- Целостность SQLite: PRAGMA integrity_check → ok; нарушений внешних ключей нет.
- Число строк road_segment в SQLite совпадает с GeoJSON и отчётом качества.
- Карта открылась в браузере; проверены поиск Р-228, открытие исходных тегов и ссылки OSM, смена профиля машины, слои и онлайн-подложка.
- В обзорном масштабе показаны магистрали и дороги среднего класса; мелкие подъезды и точки появляются при приближении, начиная с масштаба 13.
- Библиотеки Leaflet лежат локально; данные в HTML встроены. Для дорожного слоя внешний сервис не нужен. Онлайн-подложка OSM требует интернет и запуск через Открыть карту.cmd.
- PostgreSQL/PostGIS на компьютере не развёрнуты: SQL-схема и импорт подготовлены, но исполнение в PostgreSQL пока не проверено.
- Правовая полнота, актуальность ограничений на каждом участке, фактические грузовые потоки и непрерывность грузовых маршрутов не подтверждены.

Заполненность OSM: hgv указан у 71 линии (49 destination, 17 no, 5 yes); числовой maxweight — у 6, maxheight — у 46. Часть других ограничений может содержаться в общих/специальных тегах и точках. Это показатели заполненности конкретных ключей, не количество реально ограниченных дорог города.

Примерная сумма длин всех линий — 10 705,2 км. Включает подъездные дороги, треки, отдельные проезжие части и целые OSM-линии за границей запроса; это НЕ протяжённость уникальных городских улиц и НЕ протяжённость разрешённой грузовой сети.

## Проверка исправления фоновой карты

После сообщения о плитках 403 проверены: отсутствие запросов при file://; нормальное отображение HTTP 200; отбрасывание даже валидной PNG при HTTP 403; отключение слоя без повторных попыток; ошибки сети/CORS; отмена незавершённых запросов; освобождение временных адресов изображений. Проверки выполнены с локальными подставными ответами, без обращений к провайдеру.

Локальный сервер прошёл 9 проверок: выдача карты и библиотек, типы содержимого, кеширование ETag/304 и HEAD, закрытые каталоги данных/SQL, защита от выхода за разрешённые пути, проверка Host, повторный запуск только для того же приложения и папки, корректный отказ при занятом чужой программой порте.

Настоящая карта затем открыта через локальный сервер в браузере; онлайн-фон OSM успешно загрузился. Этот результат относится к проверенному браузеру и текущему доступу, а не гарантирует доступность внешнего сервиса у всех пользователей.

## Русский интерфейс и передача команде

Карточка участка Р-229 с OSM ID 43649815 проверена в браузере: highway → «Класс дороги», primary → «Основная дорога», old_ref → «Прежний номер дороги», ref → «Номер дороги», surface/asphalt → «Покрытие/Асфальт». Переведены основные атрибуты дорог и препятствий, легенда, названия слоёв и кнопки масштаба/закрытия. Технические исходные пары ключ/значение доступны отдельно в закрытом по умолчанию разделе; данные базы не переименованы.

SQLite повторно проверена при подготовке комплекта: integrity_check = ok, foreign_key_check без ошибок, числа строк совпадают с отчётом. В data/processed/handoff_manifest.json записаны контрольные суммы файлов, числа строк, географическая система и явные признаки неготовых частей: PostGIS не запущен, API и маршрутный граф отсутствуют, независимые метки ML и материалы помещений не собраны. Правила передачи и дальнейшие задачи находятся в ПЕРЕДАЧА_КОМАНДЕ.md.
