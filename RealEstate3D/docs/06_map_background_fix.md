# Обновление запуска и фоновой карты

27 октября 2026 года пользователь получил вместо фоновой карты плитки «403 Access blocked». Дорожный слой проекта и база при этом сохранились.

Скриншот содержит общий отказ по правилам OSM, поэтому конкретная причина блокировки не установлена. Предыдущая инструкция предлагала открывать HTML напрямую; такой запуск не даёт обычного HTTP-адреса страницы. Исправлен этот недостаток, но локальный сервер не гарантирует доступ, если действуют другие ограничения провайдера.

## Как открыть карту

Дважды щёлкните **Открыть карту.cmd** в корневой папке RealEstate3D. Оставьте окно запуска открытым. В браузере включите «Онлайн-фон OSM», если он нужен. После работы закройте окно запуска или нажмите Ctrl+C.

При открытии HTML напрямую работает офлайн-дорожный слой. Онлайн-фон в таком режиме отключён с пояснением. При отказе HTTP 403/429, сетевой ошибке или ошибке доступа браузера подложка отключается целиком; ошибка не используется как изображение, автоматических повторов нет. Дороги, поиск, карточки и параметры машины остаются доступны.

Сервис запуска доступен только на этом компьютере. Он не передаёт запросы фоновой карты через прокси и не подменяет заголовки браузера. Тайлы запрашиваются браузером для текущего просмотра с обычным кешированием, без скачивания области для хранения.

Правила источника: https://operations.osmfoundation.org/policies/tiles/
Пояснения по блокировке: https://wiki.openstreetmap.org/wiki/Blocked
