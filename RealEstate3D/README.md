# RealEstate3D

Платформа коммерческой недвижимости для малого и среднего бизнеса: каталог помещений,
3D-просмотр и оценка транспортной (грузовой) доступности. Первый регион — Саратов.

## Структура репозитория

| Папка | Владелец | Содержимое |
|---|---|---|
| `backend/` | Backend | API на FastAPI, модели БД, миграции Alembic, Docker |
| `frontend/` | Frontend | Сайт: каталог, карточки объектов, карта, 3D-просмотр |
| `ml/` | ML | Модель выбора лучшего места для склада |
| `data_engineering/` | Data Engineer | База дорог (OSM → SQLite / PostGIS), SQL, GeoJSON, карта дорог |
| `docs/` | Общие | Цели и план проекта, модель данных |

## Как связаны части

`data_engineering` (база дорог) → `ml` → оценки мест (GeoJSON / функция инференса) → `backend` (`/recommendations`) → `frontend` (карта на сайте).

Общие файлы в корне: этот `README.md` и `.gitignore`.

## Правила

- Каждый работает в своей папке и в своей ветке, в `main` — через Pull Request.
- Большие данные, веса моделей, `.env`, фото и видео в git не коммитим (см. `.gitignore`).
  Данные дорог собираются скриптами — инструкция в `data_engineering/README.md`.
- Общие документы (`docs/`) меняем, предупредив команду.
