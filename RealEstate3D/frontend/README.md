# Frontend

Зона фронтенд-разработчика: сайт-каталог коммерческой недвижимости, карта и 3D-просмотр помещений.

- API берётся из `../backend` (FastAPI).
- **Карта сайта — здесь.** Рекомендованные ML места для склада приходят от backend
  (`/recommendations`) в виде GeoJSON с оценкой `score`; фронт рисует их на карте.
- Образец карты дорог есть у дата-инженера: `../data_engineering/maps/` (Leaflet, `basemap.js`, русские подписи дорог).
